# Оттиск — сайт-приложение

Программа «Оттиск»: печать и подпись своей фирмы на PDF. Работает в браузере на компьютере и телефоне и без интернета после первого открытия.

**Открыть:** https://gagauz113.github.io/ottisk-web/

- Печати, подписи и документы на этот сервер **не загружаются**, они хранятся только на вашем устройстве.
- На телефоне: откройте ссылку и выберите «Добавить на главный экран». Появится иконка, программа будет работать как приложение.
- На Android документ из Telegram можно отправить прямо в «Оттиск» через «Поделиться».

Этот репозиторий собирается автоматически из основной (закрытой) программы командой `tools/publish_web.py --push`. Руками здесь ничего не правится.
